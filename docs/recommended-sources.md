# Recommended Sources

Community-maintained plugin sources you can add in the Hub (**Add Source**).

These are community forks/branches that add providers not yet in the official
[`FrankieeW/openusage-collection`](https://github.com/FrankieeW/openusage-collection)
source. Add one by pasting its URL into **Add Source**.

> ⚠️ The entries below are **not tested by me** — try them at your own
> discretion. If one works (or doesn't), please open an issue/PR so we can
> update this list.

## Sources

## Contributing

Found a useful source? Open a PR adding a row to the table above. Keep the
**Status** column honest — mark entries `⚠️ Untested` unless you've verified
them yourself, and note the provider it adds.
